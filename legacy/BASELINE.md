## Legacy evidence boundary

Results generated by this snapshot must be labeled **legacy** unless regenerated by the new CAMH-CUFE protocol, backend, experiment runner, and statistical pipeline.

Known reasons why legacy results cannot automatically become headline CAMH-CUFE evidence include:

- ambiguous/ad hoc serialization in some signed/hashed statements;
- protocol-size measurements based on Python object serialization;
- a final-proof verifier API that accepts commitment bases from the caller;
- an official test report that can skip backend-dependent tests when dependencies are unavailable;
- local/symbolic evidence that is insufficient for the planned FGCS distributed-system claims.

## Excluded material

Submission PDFs, cover letters, audit-history reports, journal-specific JISA documents, build artefacts, and presubmission screenshots are intentionally not part of the CAMH-CUFE scientific source tree.
